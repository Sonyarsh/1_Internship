# Concrete Strength API (Internship Project)

API для учета результатов испытаний бетона на прочность согласно ГОСТ 10180-2012.

## Установка и запуск

### 1. Подготовка окружения
Убедитесь, что у вас установлен Python 3.8+.

```bash
# Создание виртуального окружения
python -m venv .venv

# Активация (Windows)
.venv\Scripts\activate

# Активация (Linux/macOS)
source .venv/bin/activate
```
### 2. Установка зависимостей
```bash
pip install fastapi uvicorn sqlalchemy psycopg2-binary
```

### 3. Настройка базы данных
```
Перед запуском убедитесь, что у вас создана база данных PostgreSQL и доступны параметры подключения.
Например:

Создайте базу данных:
sql

CREATE DATABASE concrete_strength_db;
Настройте параметры подключения в вашем коде main.py или в конфигурационном файле:
python

# URL базы данных PostgreSQL
DB_URL = 'postgresql://user:password@localhost:5432/concrete_strength_db'
Замените user, password, localhost, 5432, и concrete_strength_db на ваши реальные параметры.
```
### 4. Запуск приложения
```bash

python main.py
```
Сервер запустится по адресу: [http://127.0.0.1:8080](http://127.0.0.1:8080)

## Работа с API

### Документация
После запуска доступна интерактивная документация Swagger:
[http://127.0.0.1:8080/docs](http://127.0.0.1:8080/docs)

### Основные эндпоинты
- `GET /` — Проверка работоспособности.
- `POST /concrete_strength/` — Добавление новой записи испытания.
- `GET /concrete_strength/` — Получение списка всех записей.

## База данных
Теперь в проекте используется PostgreSQL.
Конфигурацию подключения необходимо настроить под ваши параметры.
При первом запуске ORM создаст таблицы согласно моделям.

### Структура таблицы
Таблица `concrete_strengths` содержит более 50 полей, описывающих параметры образцов, результаты замеров и итоговую прочность. Поля в БД имеют кириллические алиасы для удобства экспорта.
